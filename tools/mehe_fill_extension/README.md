# MSA — تعبئة موازنة الوزارة (إضافة كروم)

تعبّئ خانات موازنة منصّة مصلحة التعليم الخاص **psb.mehe.gov.lb** من أرقام برنامج الرواتب MSA.
الإضافة **لا ترسل شيئاً**: تعبّئ الخانات فقط، وأنت تراجع كل قسم وتكبس «أرسل» على الموقع.

## التركيب (مرّة واحدة)
1. افتح كروم واكتب بشريط العنوان: `chrome://extensions`
2. فعّل **Developer mode / وضع المطوّر** (الزرّ أعلى اليمين).
3. اكبس **Load unpacked / تحميل غير مضغوط** واختر هذا المجلّد:
   `C:\Users\user\school-rawatib\saint-maxime-payroll\tools\mehe_fill_extension`
4. ثبّت الأيقونة بشريط كروم (رمز القطعة 🧩 ← الدبّوس).

## الاستعمال
1. افتح برنامج الرواتب وسجّل دخولك، واختر المدرسة والسنة من الأعلى (موازنة الوزارة جاهزة).
2. افتح psb.mehe.gov.lb ← موازنة السنة ← **أرسل الآن** (صفحة الإدخال).
3. اكبس أيقونة الإضافة ← **١) جلب الموازنة من البرنامج** ← **٢) تعبئة صفحة الوزارة المفتوحة**.
4. راجع كل قسم بـ«التالي». «مراجعة» تُظهر الموظفين الذين لم يُطابَقوا (تُطابَق الصفوف بمعرّف الموظف ثمّ بالاسم).
5. اكبس **أرسل** أنت على الموقع.

## ملاحظات
- جداول المعفيين وتعويضات الصرف تُعبَّأ على الأسطر الموجودة بالموقع؛ إن كانت أقلّ من أسطر البرنامج تُضاف الأسطر على الموقع ثمّ تُعاد التعبئة.
- الوثائق (محاضر اللجنة المالية، بيان الصندوق، إيصالات، تقرير التدقيق) تُرفَع يدوياً على الموقع.
- إذا غيّرت الوزارة شكل صفحتها تحتاج الإضافة تحديثاً.
