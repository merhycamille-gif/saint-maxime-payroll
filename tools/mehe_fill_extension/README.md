# MSA — تعبئة مواقع الدولة من البرنامج (إضافة كروم / إيدج)

تعبّئ من أرقام برنامج الرواتب MSA:
1. **موازنة منصّة مصلحة التعليم الخاص** psb.mehe.gov.lb — تعبئة الخانات فقط، وأنت تكبس «أرسل».
2. **بوّابة صندوق التعويضات** www.caisseindemnite.com — البيان العام (سنوي) والبيان المالي (فصلي): مراجعة، تعبئة النموذج المفتوح، أو ترحيل تلقائي سطراً سطراً.

## التركيب (مرّة واحدة — مركَّبة على كمبيوتر المدرسة بكروم وإيدج معاً)
1. افتح كروم واكتب بشريط العنوان: `chrome://extensions` (بإيدج: `edge://extensions`)
2. فعّل **Developer mode / وضع المطوّر** (كروم: أعلى اليمين · إيدج: أسفل اليسار).
3. اكبس **Load unpacked / تحميل غير مضغوط** واختر هذا المجلّد:
   `C:\Users\user\school-rawatib\saint-maxime-payroll\tools\mehe_fill_extension`
4. ثبّت الأيقونة بشريط المتصفّح (رمز القطعة 🧩 ← الدبّوس). بعد أيّ تحديث للإضافة اكبس «Reload» بصفحة الإضافات.

## الاستعمال — صندوق التعويضات
1. افتح برنامج الرواتب **بنفس المتصفّح** وسجّل دخولك، واختر المدرسة من الأعلى (الإضافة تقرأ من نافذة البرنامج المفتوحة).
2. افتح www.caisseindemnite.com ← البيان العام (أو المالي) ← **تعبئة** للسنة/الفصل المطلوب.
3. اكبس أيقونة الإضافة ← **١) جلب لائحة البيانات** ← اختر البيان ← **٢) جلب هذا البيان**.
4. اختر ما تريد:
   - **مراجعة**: مَن ناقص على الموقع ومَن زائد فيه (لا يغيّر شيئاً).
   - **تعبئة النموذج المفتوح**: افتح «+ إضافة» أو ✎ على الموقع فيعبّئه بالأستاذ المناسب، وأنت تكبس «حفظ».
   - **ترحيل تلقائي — الناقصين فقط**: يضيف الناقصين ويكبس «حفظ» لكل واحد تلقائياً (شريط تقدّم أعلى الصفحة + إيقاف).
   - **ترحيل تلقائي — الكل**: يضيف الناقصين ويحدّث الموجودين بأرقام البرنامج.
   حفظ السطر على الموقع يبقى قابلاً للتعديل والحذف. الإضافة لا تعتمد ولا تقفل أيّ بيان.
5. البيان المالي: الموقع يتحقّق من الرقم المالي عند الصندوق؛ أستاذ بلا رقم أو برقم غير معروف يُذكر بالملاحظات ولا يُحفَظ.

## الاستعمال — موازنة الوزارة
1. افتح البرنامج وسجّل دخولك واختر المدرسة والسنة. 2. افتح psb.mehe.gov.lb ← موازنة السنة ← **أرسل الآن**.
3. أيقونة الإضافة ← **جلب الموازنة** ← **تعبئة صفحة الوزارة المفتوحة** ← راجع بـ«التالي» ← اكبس **أرسل** أنت.

## ملاحظات
- إذا غيّر الصندوق أو الوزارة شكل صفحتهما تحتاج الإضافة تحديثاً (أسماء الخانات: `teacher_no`, `salary`, `add_salary`, `bm_*`…).
- الوثائق على منصّة الوزارة (محاضر اللجنة المالية، بيان الصندوق، إيصالات، تقرير التدقيق) تُرفَع يدوياً.
