# Payroll Multi-Écoles
## نظام إدارة رواتب وأجور متعدد المدارس

---

## 🆕 الجديد في الإصدار 2.0

- **تعدد المدارس / Multi-écoles:** أصبح بإمكانك إدارة عدة مدارس في نفس البرنامج، كل مدرسة باسمها وبياناتها المنفصلة (موظفين، رواتب...).
- **مدير عام (superadmin):** يرى كل المدارس ويبدّل بينها من القائمة بالأعلى. كل مدرسة يمكن أن يكون لها مستخدموها الخاصون الذين يرون مدرستهم فقط.
- **تقارير متعددة المدارس:** في كل تقرير يمكنك اختيار **مدرسة واحدة / عدة مدارس / الكل** ورؤية النتائج للمختار، مع تفصيل لكل مدرسة.
- **حذف / تعديل / طباعة** في كل صفحة وتقرير.
- **تصليح قانون 223/2012:** أصبح يعطي **4½ درجة** بشكل صحيح (دعم أنصاف الدرجات بقيمة مستوفاة بين الدرجتين) بدل تقريبها إلى 4.
- **القوانين وأسعار الصرف مشتركة** لكل المدارس (تعدّلها مرّة وتُطبّق على الجميع).

> **إعداد جديد:** القوانين اللبنانية وأسعار الصرف مشتركة. كل مدرسة تُدار من صفحة **Écoles / المدارس** (للمدير العام).
>
> **تحديث قاعدة بيانات موجودة:** شغّل ملفات `sql/migrations/001_multi_school.sql` ثم `002_half_grades.sql` مرّة واحدة. أو أعد التركيب عبر `install.php` لقاعدة جديدة.

**🔐 دخول افتراضي:** `admin` / `admin123` (مدير عام يرى كل المدارس).

## 🚀 التركيب / Installation

### الخطوات / Étapes:

1. **انسخ المجلد** إلى مسار XAMPP:
   ```
   \\192.168.1.60\htdocs\saint-maxime-payroll\
   ```

2. **افتح المتصفح** على عنوان:
   ```
   http://192.168.1.60/saint-maxime-payroll/install.php
   ```

3. **اضغط أي زر** لتنفيذ التركيب التلقائي:
   - إنشاء قاعدة البيانات `saint_maxime_payroll`
   - إدخال كل الجداول الأولية (سلسلة 2017، شطور الضريبة، إلخ.)
   - إعداد المستخدم الافتراضي

4. **احذف** ملف `install.php` بعد التركيب (مهم للأمان!)

5. **سجل الدخول**:
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`

## ⭐ الميزات / Fonctionnalités

### إدارة الموظفين / Gestion du personnel
- 3 أنواع موظفين: ملاك، متعاقد، إداري
- بيانات شاملة بالعربي والفرنسي
- عنوان كامل، حالة عائلية، معلومات الزوج/ة
- المؤهلات والاختصاصات

### حسابات الرواتب / Calcul des salaires
- **سلسلة الرتب 2017** كاملة (52 درجة)
- ضريبة الدخل التصاعدية حسب القانون 324/2024
- CNSS (3% موظف + 8% مدرسة)
- صندوق التعويضات EOC (6%+6%) للملاك
- تعويضات عائلية (8.5%) للموظفين
- خصومات عائلية حسب الحالة الاجتماعية

### الترقيات / Promotions
- ترقية كل سنتين تلقائياً (+1 درجة)
- تطبيق الدرجات الاستثنائية:
  - قانون 244/2000 (+3 درجات)
  - قانون 344/2001 (+4 درجات)
  - قانون 102/2010 (+3 درجات)
  - قانون 223/2012 (+4.5 درجات)
- تاريخ كامل للتعديلات

### الرواتب الشهرية / Paie mensuelle
- حساب فردي أو جماعي
- بطاقة راتب مفصلة
- محاسبة شهر التعويض (13ème mois)
- تحويل تلقائي USD/LBP

### بطاقة الراتب السنوية / Relevé annuel
- مطابقة 100% للنموذج الرسمي
- 10 أو 12 شهر حسب الموظف
- إجماليات سنوية
- قابلة للطباعة

### التقارير / Rapports
- ملخص شهري
- تقارير CNSS
- تقارير الضريبة
- تقرير الصندوق EOC
- قائمة الموظفين
- إجماليات سنوية

### النماذج الحكومية / Formulaires officiels
- R5, R6, R7, R10
- 190A (CNSS)

## 💻 الاستخدام / Utilisation

### إضافة موظف / Ajouter un employé
1. اذهب إلى **Employés** ← **Nouveau**
2. املأ المعلومات في 6 تبويبات:
   - 👤 Personnel (شخصي)
   - 🏠 Adresse (عنوان)
   - 🎓 Emploi (وظيفة)
   - 💰 Financier (مالي)
   - 🎁 Primes & Indemnités (مكافآت)
   - 🧾 Retenues (محسومات)
3. اضغط **Enregistrer**

### حساب الراتب الشهري / Calculer la paie
1. اذهب إلى **Paie mensuelle**
2. اختر الشهر والسنة
3. اضغط **Calculer tous** للجميع، أو احسب فرديًا

### بطاقة الراتب السنوية / Relevé annuel
1. اذهب إلى **Relevé annuel**
2. اختر الموظف والسنة الدراسية
3. اطبع البطاقة
