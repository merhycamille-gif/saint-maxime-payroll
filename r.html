⚠️ الزرّ يستبدل الأجر الإضافي الحالي عند كل موظفي كل فئة مؤشَّرة (كل فتراته) بسطرها. الفئات غير المؤشَّرة والأنواع التانية ما بتتأثّر. شخص بدّك تخلّيه على شي مختلف؟ بعد التطبيق عدّله من ملفه ← تبويب «المكافآت». كل متعاقد إلو رقمه (مبلغ بالدولار و/أو بالليرة)؟ ما تستعمل هالبطاقة — زرّ «مبالغ فردية (لكل واحد)» تحت، أو إكسل.
كيف بشتغل بهالصفحة؟ (اكبس للشرح)
  1. لكل فئة رقمها دفعة وحدة؟ البطاقة الكحلية فوق: شو (أجر إضافي/مكافأة/نقل شهري) ← أشّر الفئات وحطّ لكل واحدة رقمها (الملاك نسبة ٪ مثلاً، المتعاقدون نسبة تانية أو مبلغ، الموظفون مبلغ تالت) ← من شهر إلى شهر ← «طبّق». الفئة غير المؤشَّرة ما بتتأثّر. خلص.
  2. «+ بند جديد» (لأي نوع/فئة/فترة) ← اختر الفئة (ملاك / متعاقدين / موظفين) ← كل سطر = بند: النوع (أجر إضافي / مكافأة ومساعدة / نقل شهري) + نسبة ٪ أو مبلغ ثابت + الفترة ← «طبّق». البرنامج بيعيد حساب رواتب الفئة لحاله.
  3. النسبة ٪ بتنحسب من أساس الراتب بعد التدرّج (÷1500 ← × سعر الشهر) وبتتحرّك مع الدرجة — منطقية للملاك. المبلغ الثابت بالليرة أو بالدولار — للمتعاقدين والموظفين أو لأي زيادة ثابتة.
  4. نسبة + مبلغ ثابت مع بعض (مثلاً 45٪ + 2,000,000 ثابت): حطّهم سطرين بنفس النافذة وكبس طبّق مرّة وحدة. (لو طبّقتهم بمرّتين منفصلتين، التانية بتشيل الأولى لأنها من نفس النوع.)
  5. كل واحد إلو رقمه (المتعاقدون، أو أستاذ ملاك بدّك تعطيه شي خاص): زرّ «مبالغ فردية (لكل واحد)» ← جدول بأسماء الفئة، قدّام كل اسم ولكل نوع ثلاث خانات نسبة ٪ + مبلغ بالليرة + مبلغ بالدولار — عبّي وحدة أو أكثر (متعاقد بياخد جزء بالدولار وجزء بالليرة = عبّي الخانتين) واحفظ مرّة وحدة. فاضي = ما بيتغيّر، 0 = شيله.
  6. الجدول تحت = البنود السارية: تعديل سطر لحاله · حذفه. «نقل يومي» للمتعاقدين حسب أيام الحضور. استثناء لشخص واحد: من ملفه ← تبويب «المالي».

مبالغ فردية — لكل موظف رقمه

قدّام كل اسم ولكل نوع ثلاث خانات: نسبة ٪ (من أساس الراتب بعد التدرّج) + مبلغ بالليرة + مبلغ بالدولار — عبّي وحدة أو الاتنين أو التلاتة، والبرنامج بيجمعهم (مثلاً متعاقد: 100 $ + 5,000,000 ل.ل بالشهر). القيم شهرية. فاضي = ما بيتغيّر · 0 = شيله. الخانات تعرض قيم «كل السنة»؛ لتفاصيل فترات شخص: من ملفه ← تبويب «المكافآت».
📅 الفترة لكل ما تحفظه الآن: من إلى افتراضياً كل السنة (تشرين ← أيلول). فترة أقصر = يُضاف/يُستبدل بند لهذه الفترة فقط.
